# Problems
1. Create a table `stock_details` with appropriate type for every CSV column. Choose and justify primary key.
2. Import the CSV data into `stock_details`. How many rows were loaded?
3. Write a query that displays the first 10 records ordered by date.
4. How many distinct companies are included in the dataset?
5. Find the earliest and latest trading date available for each company.
6. List the 10 companies with the highest total trading volume across the full dataset.
7. Aggregate the total trading volume for each company.
8. Identify stock-split events. For each event, return the company, date, and split value.
9. Find companies that paid dividends and show their total dividends paid over the dataset period.
10. Create a view named `company_yearly_summary` containing each company’s yearly average close, maximum close, minimum close, and total volume.
